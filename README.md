# Olá, sou Pedro!

Desenvolvo projetos em Python para automatizar o tratamento de planilhas, organizar informações e verificar a qualidade dos dados.

Meu foco está na construção de processos ETL reproduzíveis, com validações, rastreabilidade e testes automatizados.

## Tecnologias que utilizo

- **Python:** automação e processamento de dados.
- **pandas e openpyxl:** leitura, transformação e exportação de planilhas Excel.
- **unittest:** testes automatizados.
- **GitHub Actions:** execução dos testes e dos pipelines.

## Projeto em destaque

### [ETL de Dados Hospitalares](https://github.com/ppsgaspari-afk/etl-dados-hospitalares)

Projeto de portfólio com quatro módulos: IAM, AVC, medicamentos e inspeções hospitalares.

O projeto demonstra:

- Padronização e consolidação de múltiplas planilhas.
- Identificação de inconsistências e possíveis duplicidades.
- Rastreabilidade dos registros até os arquivos de origem.
- Geração de relatórios para conferência.
- Testes automatizados e execução com GitHub Actions.

Os exemplos utilizam dados sintéticos para demonstrar o processamento sem expor informações reais de pacientes ou inspeções.
